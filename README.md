# MATTHIEUSAA — Laptops & Technology

An elegant, responsive technology storefront concept in English for **MATTHIEUSAA**.

## Getting started

Open `index.html` in a browser to preview. All essential design assets are stored locally in `assets/`; the optional Google Fonts stylesheet needs internet and falls back to system fonts.

## Features

- Premium white-and-navy aesthetic with electric-blue accents
- Fully responsive navigation, hero and product catalog
- Filterable product gallery (Business, Creative, Gaming, Everyday)
- Interactive demonstration shopping bag with illustrative total
- Custom, original SVG laptop artwork and favicon
- About, collection, category and contact sections
- Semantic HTML, keyboard focus styles, mobile navigation and accessible labels

## GitHub Pages publishing

1. Create the repository `matthieusaa.github.io` under your `matthieusaa` GitHub account.
2. Upload `index.html` and the `assets` folder to the repository root (you can also upload this README).
3. In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Once deployed, visit https://matthieusaa.github.io/ .

## Important demo disclosures

This is a **concept site**, not a functioning store. All model names, specifications, product prices, badges, and inventory presentations are illustrative and do not correspond to verified products for sale. The cart is local to the browser session and does not accept orders or payments. The contact section links to the brand's public GitHub profile rather than inventing an email or address. For a commercial launch, replace the concept catalog with verified products and inventory, add real contact/legal information, and integrate a commerce backend and payment processing.
